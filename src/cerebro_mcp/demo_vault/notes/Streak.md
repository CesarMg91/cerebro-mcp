# Streak

Habit tracker for people who quit habit trackers. One screen, one tap per
habit, no guilt.

Una app de hábitos para la gente que ya abandonó otras apps de hábitos.

## What it is

- Offline-first: everything lives in a local SQLite file on the phone; sync is
  optional and Pro-only. See [[Sync architecture]].
- Free tier: up to 3 habits. Pro unlocks unlimited habits, widgets and history
  export.
- iOS and Android from one codebase. Built solo, evenings and weekends.
